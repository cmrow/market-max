# 🛠️ API RESTful  Market-max - E-Commerce Node.js + Express

Este proyecto es una **API RESTful** para un sistema de e-commerce construida con Node.js, Express y MongoDB. Está desarrollada siguiendo la arquitectura MVC y estructurada para facilitar la escalabilidad, mantenibilidad y extensibilidad futura.

---

## 📁 Estructura Actual

### 🧱 Arquitectura General

- API RESTful construida con **Node.js** y **Express**
- Estructura **MVC (Model-View-Controller)**
- Base de datos **MongoDB** utilizando **Mongoose**
- Sistema de rutas **versionado (v1)**

### 📦 Componentes Principales

- **Modelos**: `User`, `Product`, `Category`, `Brand`, `Color`, `Review`, `Order`, `Coupon`
- **Controladores**: Lógica de negocio para cada entidad
- **Rutas**: Endpoints RESTful organizados por recurso
- **Middleware**: Manejo global de errores, autenticación y validación

### ✅ Características Implementadas

- 🔐 Sistema de usuarios y autenticación
- 📦 Gestión de productos y categorías
- 🌟 Sistema de reseñas
- 📦 Gestión de órdenes
- 🎟️ Sistema de cupones
- 🏷️ Manejo de marcas y colores
